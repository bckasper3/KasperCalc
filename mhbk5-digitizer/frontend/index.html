How to use this tool

First-time setup: Click "Build catalog" below — this scans the whole handbook PDF once (~1700 pages, takes under a minute) and lists every figure it can find along with its page number. You only need to do this once; the list is saved.

Finding a figure: Use the two search boxes — search by page number if you know roughly where to look, or search by figure number (e.g. "3.2.1.1.6") if you know which figure you need. Click any row's "Open" button to load it into the editor.

In the editor:

  1. Click "Calibrate" next to an axis, then click two known points on the chart's gridlines and type in their real values (repeat for each axis — charts can have more than one Y axis).
  2. Click on a curve in the image to select it, type a label for it (e.g. "Tension"), assign it to the right X/Y axes, and click "Create dataset from selected paths".
  3. Repeat for every curve on the chart.
  4. Check the Live Preview panel — it should visually match the original chart. If it looks wrong, your axis calibration is the most likely culprit.
  5. Add any notes, then click Save.

Marking it done: Go back to the catalog list (there's a "Back to catalog" button in the editor) and check the checkbox next to that figure's row. This checkbox is yours to track your own progress — it's separate from the Approve/Flag buttons in the editor, which are optional QC status.

Select or create a figure to begin.

Axes iEvery figure starts with one X and one Y axis (x1/y1) — calibrate those first. Add more only if this chart has a second Y axis (e.g. stress and tangent modulus sharing one X axis). Calibration converts raw pixel coordinates on the page into real data values — every dataset depends on the calibration of the axes it's assigned to.

Datasets iA dataset is one curve: a label, the X/Y axes it's measured against, and the pixel points that make it up. If a curve has a break or interruption, click every one of its segments in the viewer (they all stay highlighted) before clicking "Create dataset" — all selected segments merge into a single curve. Clicking "Calibrate + Preview" converts each dataset's raw pixel points into real values using its assigned axes' calibration.

Notes iYour own QC remarks — anything worth flagging for yourself or a reviewer (calibration uncertainty, overlapping curves, "see Table 3.x", etc). Saved with the figure but not included in the exported Chart.js data.

Live Preview iA Chart.js rendering of your calibrated dataset points, grouped by Y axis. Use it to visually sanity-check your calibration against the original chart before trusting the exported numbers — a wrong calibration still produces a plausible-looking but incorrect curve.
